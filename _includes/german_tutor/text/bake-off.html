The bake-off: every phone-sized model, same eval

Once the eval harness existed, any candidate model was one command away from a scorecard — so the project turned into an accidental survey of German competence across the current open-weight, phone-sized field. It kept growing: twenty-seven models in the end, over three sweeps months apart. Several besides the E4B also got the identical fine-tune — same dataset, same QLoRA recipe, same cheap pod — which turned out to be the most instructive experiment of the project. The funnel below is how the field narrowed; the tables and chart after it are the full results. (Every number in the first table scores the raw checkpoint — a later section, "The eval was lying," revisits how the app actually renders corrections, and it matters more than I knew. The second table covers two sweeps that happened after that fix, so it is already scored the app's way.)
